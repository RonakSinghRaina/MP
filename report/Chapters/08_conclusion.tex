\chapter{Conclusion}
\label{ch:conclusion}
This project tested U-Net-based RFI detection on real telescope data with an
existing method, \tfunet{}, and a new network, \hybrid{}. The main results are:
\begin{itemize}
  \item \textbf{Results on synthetic data do not carry over to real data.}
    \tfunet{} scored a maximum \Fone{} of 0.93 on our synthetic data but only
    0.49 on real LOFAR data with the same settings.
  \item \textbf{\hybrid{} beats the published methods on LOFAR.} With our
    training settings it scored $0.6603 \pm 0.0040$, above \tfunet{} (0.5482) and
    RFI-Net (0.5979), the best method reported by Mesarcik et al., with under
    600{,}000 parameters.
  \item \textbf{With the authors' own settings it matches their U-Net with half
    the parameters:} 0.6258 against 0.6166 (one run each). Running their
    released code gave 0.6207 instead of their published 0.5876; we could not
    find out why.
  \item \textbf{Expert labels help.} Fine-tuning on the expert labels of about
    68 images raised the score to $0.6747 \pm 0.0083$.
  \item \textbf{The new components are not the reason for the gain.} Removing
    the strip convolutions, channel attention and residual blocks changed
    nothing measurable, and adding a CRF did not help. The Dice loss explains
    about a tenth of the lead over \tfunet{}; the rest is still unexplained.
  \item \textbf{Public datasets need checking.} Both the HERA and the LOFAR
    datasets contain test images that also appear in their training sets.
\end{itemize}
The main lesson is simple: a method has to be tested on real data, with
several runs, before we can trust why it works. All code, analysis scripts and per-run results are available at
\url{https://github.com/RonakSinghRaina/MP}.
